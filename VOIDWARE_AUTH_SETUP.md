# VoidWare: подключённая авторизация

## Локальный тест
1. `pnpm install`
2. В `api/private/logins.txt` строка `Admin 1234Pass`
3. В `api/private/keys.txt` есть демонстрационный ключ `VW-ADMIN-ALPHA-7K9Q-2M4X` со сроком 26-12-2026 и уровнем alpha.
4. `pnpm dev`, открой `/login`.

## Для публикации на Vercel (обязательно)
Файлы в `api/private` намеренно исключены из Git, чтобы они не утекли через публичный репозиторий. В Vercel → Project → Settings → Environment Variables добавь:
- `VOIDWARE_LOGIN_DATA` = содержимое `logins.txt`
- `VOIDWARE_SUBSCRIPTION_KEYS` = содержимое `keys.txt`
- `SESSION_SECRET` = длинная случайная строка, уникальная для проекта
- `NEXT_PUBLIC_LAUNCHER_URL` = ссылка на установщик, если она готова

Не называй секреты `NEXT_PUBLIC_*`, не добавляй приватные txt-файлы в Git. Поскольку Vercel serverless не предназначен для постоянного изменения файлов, аккаунты/ключи добавляй через обновление переменных окружения или позже перенеси их в БД. Пароли в текущем формате хранятся как plaintext согласно запрошенному формату: для публичного production-проекта настоятельно рекомендуется заменить это на хеширование паролей и базу данных.

## Реализовано
- проверка логина/пароля, затем ключа и даты окончания
- alpha/admin для админского ключа, обычный уровень и USER для тестового ключа
- кабинет `/account`, ник, уровень, префикс, дата окончания и кнопка загрузки
- авто-вход через подписанную HttpOnly / SameSite=Strict cookie (без localStorage)
- logout, серверная проверка сессии

Демо доступ:
- логин: `Admin`
- пароль: `1234Pass`
- ключ: `VW-ADMIN-ALPHA-7K9Q-2M4X`
